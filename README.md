## How it's built

Plain HTML and CSS with no framework or build step, hosted on GitHub Pages.

```
index.html          home page: about, skills, experience, projects, resume, contact
style.css           shared styles, including the mobile layout
projects/           one page per project
images/             screenshots and covers
resume/             resume PDF linked from the home page
```

To run it locally, open `index.html` in a browser.
